# Artiou 中国市场内容矩阵：巴黎博物馆艺术小白（2026-06-15）

## 目标与定位

- **目标用户**：准备巴黎自由行、第一次逛卢浮宫/奥赛/橘园、对艺术史不熟但想少踩坑、拍得好看、看得懂的中文用户。
- **渠道优先级**：小红书图文/笔记、抖音 30–60 秒短视频；同步可改写为微信朋友圈/群分享文案。
- **核心承诺**：不用懂艺术史，也能用手机中文讲解在巴黎博物馆看懂重点作品。
- **主 CTA**：收藏路线 → 打开中文落地页 → 下载 Artiou → 到馆拍照识展/听中文讲解。

## 通用内容模板与复用规则

### 单条内容标准结构

1. **0–3 秒钩子 / 首图标题**：直接命中痛点，例如“第一次去卢浮宫别乱逛”。
2. **用户场景**：说明适合谁、什么时候用，例如“只有 2 小时 / 带爸妈 / 不懂艺术”。
3. **3 个可执行点**：路线、作品看点、避坑动作；每点控制在 1 句话。
4. **Artiou 使用瞬间**：展示“拍作品 → 中文讲解 → 收藏/继续路线”。
5. **CTA**：收藏本条 + 点击主页/评论链接打开中文页 + 下载 Artiou。

### 图文笔记模板

- 封面：大字痛点 + 博物馆/作品名 + “艺术小白版”。
- 6–8 页结构：痛点 → 路线/作品清单 → 每个点 1 句解释 → 避坑 → App 使用 → CTA。
- 标题公式：`场景 + 痛点 + 结果`，例如“第一次去卢浮宫，只看这 5 件也不亏”。

### 短视频模板

- 时长：30–60 秒，1 个主题只讲 1 个结论。
- 镜头：外观/排队/地图 2 秒 → 作品或路线 20 秒 → 手机中文讲解 8 秒 → 总结 CTA。
- 口播节奏：先说“不要做什么”，再给“照着做”的路线。

### 复用规则

- 每个选题先做小红书图文；数据好（收藏率高、评论问路线）再改成抖音短视频。
- 每条内容只导向 1 个目标 URL，避免 CTA 分散。
- 评论区固定追问收集：时间预算、同行人、想看作品；高频问题沉淀为下一条内容。
- 同一选题可用 3 个版本复用：`路线版`、`避坑版`、`60 秒作品版`。
- 所有 CTA 链接建议带 UTM：`utm_source=xiaohongshu|douyin&utm_medium=social&utm_campaign=paris_art_beginner_202606&utm_content=<slug>`。
